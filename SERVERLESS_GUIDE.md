# RunPod Serverless Deployment Guide

## Почему Serverless?
Вы просили оплату **только за секунды генерации**. Обычный Pod берет деньги за всё время, пока он включен (даже если простаивает).
**RunPod Serverless** запускает контейнер только когда приходит задача, выполняет её за 10-30 секунд и выключается (или засыпает). Это идеальный вариант для Telegram-бота.

## Архитектура
1.  **Telegram Bot**: Работает где-то на дешевом сервере (или даже на вашем ноутбуке/телефоне 24/7, или на бесплатном хостинге типа Render/Heroku). Он "легкий".
2.  **RunPod Serverless**: Тяжелый "мозг". Бот шлет ему JSON -> RunPod просыпается -> Генерирует -> Отдает картинку -> Засыпает.

## Инструкция по развертыванию (Serverless)

### 1. Подготовка Docker образа
Для Serverless нам нужен Docker образ, который содержит ComfyUI и наш код обработчика (`engine/serverless_handler.py`).
*   Мы должны собрать образ и запушить его в Docker Hub (или RunPod Container Registry).

### 2. Создание Endpoint на RunPod
1.  Go to **Serverless** > **New Endpoint**.
2.  **Container Image**: Укажите наш образ (например, `myuser/uberreal-worker:v1`).
3.  **GPU**: RTX 4090 (или A40 для видео).
4.  **Idle Timeout**: 60-120 секунд (чтобы не убивал контейнер сразу, если юзер делает серию запросов - "теплый старт").
5.  **FlashBoot**: Enable (быстрый старт).

### 3. Подключение Бота
В переменные окружения Бота нужно добавить:
*   `RUNPOD_API_KEY`: Ваш API ключ.
*   `RUNPOD_ENDPOINT_ID`: ID созданного эндпоинта.

Теперь Бот будет дергать API RunPod, и деньги будут списываться только за время обработки запроса.
